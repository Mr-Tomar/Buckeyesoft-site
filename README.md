## 🚀 Deployment

This repository is configured for GitHub Pages.

### Deployment process

1. Update the website files.
2. Commit the changes to the `main` branch.
3. Push the changes to GitHub.
4. GitHub Pages builds and publishes the website.

### Custom domain

The intended production domain is:

https://buckeyesoft.com

The custom domain and DNS configuration must be configured in the repository's GitHub Pages settings and the domain registrar.
